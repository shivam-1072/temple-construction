# Images — drop files here, the site picks them up by itself

## Names the site already uses
- hero-best.jpg — big photo behind the top section (your best temple, wide shot)
- project-1.jpg … project-9.jpg — main photo of each temple (1200×800)
- restore-before.jpg / restore-after.jpg — before/after slider pair (same view!)
- team-1.jpg, team-2.jpg, team-3.jpg — person photos (600×750 portrait).
  If missing, a stylish initial-letter card shows instead — nothing breaks.
- og-cover.jpg — WhatsApp / Google preview (1200×630)

## Extra photos inside one project (popup gallery)
No code change needed — just add files next to the main photo:

  project-1-2.jpg, project-1-3.jpg, project-1-4.jpg … (any number)

The popup finds them by itself. Delete a file and it disappears by itself.
Same trick works for any project: project-4-2.jpg, project-4-3.jpg …
JPG, WEBP or PNG all work — keep the same extension style as the main photo.
